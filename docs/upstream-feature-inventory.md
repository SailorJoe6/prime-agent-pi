### Skill selection and name collisions

**Assessment: partial — name collision handling exists, but the default winner differs.** Upstream v0.10.5 resolves bundled skills ahead of explicit `--skill` and other discovered sources. A global `skills` exclusion such as `"-goal"` can restore a same-name override. The [upstream loader and resource tests](https://github.com/PrimeIntellect-ai/prime-agent/blob/033eea1705c5ae953fe7cd7a5e7e7c45317e0dfe/crates/pa-core/src/resources/mod.rs#L160-L201) and its [global-exclusion fixture](https://github.com/PrimeIntellect-ai/prime-agent/blob/033eea1705c5ae953fe7cd7a5e7e7c45317e0dfe/crates/pa-core/src/resources/mod.rs#L742-L775) show both behaviors.

Pi already resolves collisions and reports losers. Its [package-manager precedence](https://github.com/SailorJoe6/prime-agent-pi/blob/6cd28f90e2391441850485c94b3ff099f579ef7a/packages/coding-agent/src/core/package-manager.ts#L171-L186) puts bundled resources last among resolved sources. A [bundled-skills test](https://github.com/SailorJoe6/prime-agent-pi/blob/6cd28f90e2391441850485c94b3ff099f579ef7a/packages/coding-agent/test/builtin-skills.test.ts#L48-L63) checks that a same-name user entry comes first, and the [skills guide](https://github.com/SailorJoe6/prime-agent-pi/blob/6cd28f90e2391441850485c94b3ff099f579ef7a/packages/coding-agent/docs/skills.md#built-in-skills) documents user, project, package, and explicit-path overrides plus built-in exclusions. This is a compatibility difference, not permission to reverse the Pi default. **Next:** compare the effects of these defaults on existing same-name overrides and explicit `--skill` integrations. Bring any unavoidable change to documented Pi behavior to Joe before adopting it.

Fresh root sessions also show a [display-only warning](https://github.com/PrimeIntellect-ai/prime-agent/blob/033eea1705c5ae953fe7cd7a5e7e7c45317e0dfe/crates/pa-core/src/session_engine/skill_problems_notice.rs) for load problems.

The [invalid-YAML and collision tests](https://github.com/SailorJoe6/prime-agent-pi/blob/6cd28f90e2391441850485c94b3ff099f579ef7a/packages/coding-agent/test/skills.test.ts#L40-L183) cover discovery with warnings, and the [interactive startup renderer](https://github.com/SailorJoe6/prime-agent-pi/blob/6cd28f90e2391441850485c94b3ff099f579ef7a/packages/coding-agent/src/modes/interactive/interactive-mode.ts#L2936-L2948) shows resource diagnostics. ### Skill references in prompts

**Assessment: partial — leading invocation is present; inline and multiple references are not equivalent.** Upstream v0.10.5 keeps the leading `/skill:<name>` form. It also expands standalone references anywhere outside code, once per skill, including prompt-hidden skills. The [expander and tests](https://github.com/PrimeIntellect-ai/prime-agent/blob/033eea1705c5ae953fe7cd7a5e7e7c45317e0dfe/crates/pa-core/src/skills/mod.rs#L272-L319), [hidden-skill fixture](https://github.com/PrimeIntellect-ai/prime-agent/blob/033eea1705c5ae953fe7cd7a5e7e7c45317e0dfe/crates/pa-core/src/skills/mod.rs#L482-L509), and [TUI unknown-name test](https://github.com/PrimeIntellect-ai/prime-agent/blob/033eea1705c5ae953fe7cd7a5e7e7c45317e0dfe/crates/pa-tui/tests/skills_menu_headless.rs#L544-L563) distinguish expansion from the notice for an unknown reference that remains plain text.

Pi's [prompt expander](https://github.com/SailorJoe6/prime-agent-pi/blob/6cd28f90e2391441850485c94b3ff099f579ef7a/packages/coding-agent/src/core/agent-session.ts#L6211-L6234) only handles a leading command and looks up the skill in the full loaded list. The [skills guide](https://github.com/SailorJoe6/prime-agent-pi/blob/6cd28f90e2391441850485c94b3ff099f579ef7a/packages/coding-agent/docs/skills.md#how-skills-work) documents explicit invocation of prompt-hidden skills, and the [submission test](https://github.com/SailorJoe6/prime-agent-pi/blob/6cd28f90e2391441850485c94b3ff099f579ef7a/packages/coding-agent/test/suite/agent-session-prompt.test.ts#L209-L244) checks a leading command and its arguments. Pi [can reject a mistyped leading command](https://github.com/SailorJoe6/prime-agent-pi/blob/6cd28f90e2391441850485c94b3ff099f579ef7a/packages/coding-agent/test/agent-session-slash-guard.test.ts#L210-L231), but this does not provide mid-message notices. **Next:** compare fixtures for a leading command with arguments, repeated and distinct inline names, hidden names, a typo, code and path literals, and a pre-expanded handoff. Check where these meet existing slash-command and extension routing before treating the leading behavior as interchangeable in all modes.

### Python skill source switching

**Assessment: unresolved for the switched import; base editable installation is present.** Upstream v0.10.5 aims to import the selected copy when switching between a bundled skill and a same-name override. Its [venv synchronization](https://github.com/PrimeIntellect-ai/prime-agent/blob/033eea1705c5ae953fe7cd7a5e7e7c45317e0dfe/crates/pa-core/src/kernel/bootstrap/venv.rs#L186-L278) drops displaced records and removes distributions that would still shadow the selected import; its [switching fixture](https://github.com/PrimeIntellect-ai/prime-agent/blob/033eea1705c5ae953fe7cd7a5e7e7c45317e0dfe/crates/pa-core/src/kernel/bootstrap/venv/tests.rs#L1144-L1223) checks source replacement. The editable-install mechanism is not itself a parity target; what matters is which callable the user gets.

Pi [syncs selected Python skills as editable installs](https://github.com/SailorJoe6/prime-agent-pi/blob/6cd28f90e2391441850485c94b3ff099f579ef7a/packages/coding-agent/src/core/kernel/bootstrap.ts#L844-L918), uses a path-keyed install record, and has [bootstrap tests](https://github.com/SailorJoe6/prime-agent-pi/blob/6cd28f90e2391441850485c94b3ff099f579ef7a/packages/coding-agent/test/kernel-bootstrap.test.ts) for initial setup and reuse. The inspected sync path does not explicitly remove a different distribution that exposes the same import name. That alone does not establish which copy a fresh Pi kernel would import on a source switch. **Next:** in a disposable venv, compare import origins on a bundled → override → bundled sequence using local fixtures, first with different distribution names and then with the same distribution name. Check the marker and Python import origin at each new session. Link any analogous defect to TASK-1 rather than opening a speculative feature task.
